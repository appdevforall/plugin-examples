AI Agent Local — On-Device Inference

AI Agent Local adds the local backend to AI Core, which routes requests from the Agent chat, Code Suggestions, Speech to Text and Vector Search. Install AI Core as well — without it this plugin has nothing to register with.

What it does

  • Runs a .gguf model through a bundled, prebuilt llama.cpp library. Requires a 64-bit ARM device (arm64-v8a).
  • Streams tokens as they are generated, and stops early when you press Stop.
  • Needs no network access — this plugin declares no INTERNET permission at all.

The settings pane

Open Preferences → Configuration → Agent and select the local backend. This plugin's own pane appears below it, with four controls:

  • Browse — opens the system file picker to choose a .gguf model. A model selected as a content:// document is copied once into the plugin's private storage so the native loader can open it, and only the current model is kept on disk. If the file is larger than the device's free RAM, a warning asks you to confirm before loading.
  • Load from saved — reloads the model already in private storage without picking it again. Use this after restarting the IDE, or when a load failed for a transient reason such as low memory.
  • SHA-256 — optional. Paste the checksum published alongside the model download to keep a record of which exact file is configured. It is stored as typed and never sent anywhere; the plugin does not compute or compare it for you. Leave it empty if you don't need the record.
  • Use simple local prompt — sends a shorter system prompt instead of the full tool-calling one. On by default, because small on-device models follow a short prompt far more reliably. Turn it off only if you are running a larger model that handles the longer prompt.
Embedding-only .gguf files cannot serve chat requests. Selecting one for chat is rejected with a clear error rather than crashing the IDE.

Privacy

Prompts, file contents and generated text stay on the device. Nothing is transmitted anywhere.

Troubleshooting

  • "No model configured" — pick a .gguf file with Browse in the settings pane above.
  • Load fails with a memory message — close other apps, or choose a smaller or more heavily quantized model (a Q4_K_M build of a 1–3B model is the safest starting point).
  • The local backend never appears — AI Core isn't installed or activated; install it and restart the IDE.
