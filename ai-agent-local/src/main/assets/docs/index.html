AI Agent Local — On-Device Inference

AI Agent Local is a headless plugin: it has no screens of its own. It adds the local backend to AI Core, which routes requests from AI Assistant, Code Suggestions, Speech to Text and Vector Search. Install AI Core as well — without it this plugin has nothing to register with.

What it does

  • Runs a .gguf model through a bundled, prebuilt llama.cpp library (arm64-v8a).
  • Streams tokens as they are generated, and stops early when you press Stop.
  • Needs no network access — this plugin declares no INTERNET permission at all.

Choosing a model

There is no settings screen here. Pick the model file in AI Assistant → AI Settings; this backend reads that choice at request time. A model selected as a content:// document is copied once into the plugin's private storage so the native loader can open it, and only the current model is kept on disk.

Embedding-only .gguf files cannot serve chat requests. Selecting one for chat is rejected with a clear error rather than crashing the IDE.

Privacy

Prompts, file contents and generated text stay on the device. Nothing is transmitted anywhere.

Troubleshooting

  • "No model configured" — pick a .gguf file in AI Assistant's settings.
  • Load fails with a memory message — close other apps, or choose a smaller or more heavily quantized model (a Q4_K_M build of a 1–3B model is the safest starting point).
  • The local backend never appears — AI Core isn't installed or activated; install it and restart the IDE.
