AI Core — Inference Router

AI Core is a headless plugin: it has no screens of its own. It provides the shared LLM inference service that the other AI plugins (AI Assistant, Code Suggestions, Speech to Text, Vector Search) call at runtime.

AI Core provides no models of its own. Install at least one backend plugin alongside it, or every request fails with "Backend not found". Install order does not matter — a backend registers itself as soon as AI Core is active.

Backend plugins

  • AI Local Backend — runs a .gguf model through a bundled, prebuilt llama.cpp library. Nothing leaves the device.
  • AI Gemini Backend — calls Google's Gemini API over HTTPS. Requires a Gemini API key, entered in AI Assistant → AI Settings. The key is sent as an x-goog-api-key header, never in a URL.

Choosing / configuring a model

AI Core has no settings screen of its own — the backend choice, model file, and Gemini API key are all configured from AI Assistant → AI Settings. AI Core reads that configuration at request time and routes to whichever backend is registered under it.

Privacy

AI Core itself declares no permissions and opens no connections; it only hands requests to a backend. What happens to your prompt depends on which backend serves it — see that plugin's own help page.

Troubleshooting

  • "LlmInferenceService not available" in another plugin — AI Core isn't installed/activated, or the IDE needs a restart.
  • "Backend '…' not found" — no backend plugin is installed, or the one selected in AI Settings isn't. Install AI Local Backend or AI Gemini Backend and restart the IDE.
  • "No model configured" — pick a .gguf file (Local) or set an API key (Gemini) in AI Assistant's settings.
  • Backend-specific errors — open that backend plugin's help page; AI Core passes its message through unchanged.
