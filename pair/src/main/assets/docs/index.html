Pair

Real-time pair programming between devices on the same WiFi — shared editing, live cursors, no server and no account.

What Pair does

Pair turns Code on the Go into a collaborative editor. One device hosts a session, others join, and from then on edits, cursor positions, and file opens flow between the devices as they happen. The devices talk directly to each other over your local network — nothing leaves the WiFi you are on.

Everything lives in the Pair editor tab. Open it from the tab bar or from Pair in the side menu.

Host a session

  1. Open the Pair tab.
  2. Tap Host session.
  3. An invite card appears with your address and a QR code:
192.168.1.23:9376

Your partner scans the QR code, or types this address on their device.

Keep the session running while your partner joins. Each connected peer shows up in the peer list with their name, role, and color.

Join a session

  1. Make sure you are on the same WiFi network as the host.
  2. Open the Pair tab and tap Join.
  3. Scan the host's QR code, or type the ip:port address shown on the host's invite card.

Once connected, the file the host is working in opens on your device with the exact same contents, and you start editing together immediately.

Past sessions

The Pair Home screen lists your recent sessions, newest first. Tap one to reconnect with the same address, or use its menu to rename or delete it. Sessions are stored on your device only.

Troubleshooting

The join fails or times out

  • Confirm both devices are on the same WiFi network — mobile data or a guest network on one device breaks the connection.
  • Re-check the address: it must match the host's invite card exactly.
  • Restart the session on the host to get a fresh invite card.

"Version mismatch" when joining

The two devices run different versions of the Pair plugin. Update both to the same version and host the session again.

The files no longer match

If a change cannot be applied cleanly, Pair marks the file out of sync rather than guessing. Have the host reopen the file — reopening sends a full snapshot and both sides converge again.
